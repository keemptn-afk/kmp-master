Tracking System (Triple-Barrier)

Every fired trade is tracked through its life via the Triple-Barrier method (López de Prado 2018, "Advances in Financial Machine Learning").

Barriers — 20 TP × 20 SL = 400 combinations

For each open position, the EA records the first-touch hour at every barrier:

  • TP barriers: +0.5, +1.0, +1.5, ..., +10.0 ATR (20 levels, step 0.5)
  • SL barriers: -0.5, -1.0, -1.5, ..., -10.0 ATR (20 levels, step 0.5)
  • Stored as hours_to_tp_NN / hours_to_sl_NN (-1 if never touched)

This enables true first-touch logic in analysis — for any (TP, SL) combo:

  • If both touched → whichever has smaller hours wins
  • If only TP → +TP/SL R units win
  • If only SL → -1.0 R loss
  • If neither → use realized pnl_atr_final scaled by SL

Used to construct trade trajectory and time-decay analysis post-hoc.

v4.1 Additional Tracking

  • HTF D1 context at entry: trend (up/down/range), atr_ratio (D1/TF), rsi, dist_to_ema200
  • Spread anomaly: ratio of current spread vs avg of last 20 bars
  • Swing distance: ATR units to nearest 3-bar pivot high/low (50-bar lookback)
