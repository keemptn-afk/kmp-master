  • SL timestamps now recorded: 20 SL barriers × first-touch hours · was boolean flags only
  • True first-hit logic: No more MAE peak proxy · ambiguous ordering eliminated
  • Buffer 50K: Was 10K → BTC/ETH M15 selection bias eliminated
  • Bulkowski compliance: WRB 1.5→2.0 · PinBar 60→66.7% · LongWick 60→66.7%
  • Early-exit: ±10 ATR or 240h cap → tracking time -70%, runtime improved 5x

Schema (v4.1, 131 cols)

  • A. Trade meta (22): ticket, symbol, TF, ea_version, direction, pattern_id/name/class/phase, prices, times, exit_reason, spreads, volume, profit_atr
  • B. Indicators at entry (23): ATR/RSI/MACD/EMA/BB/ADX/Ichimoku/volume
  • C. MFE/MAE peak (6): mfe_atr, hours_to_mfe, mfe_pct_of_life, mae_atr, hours_to_mae, mae_pct_of_life
  • D. TP barriers × 20: hours_to_tp_05 ... hours_to_tp_100 (0.5-10.0 ATR)
  • E. SL barriers × 20: hours_to_sl_05 ... hours_to_sl_100
  • F. Touch counts (5): entry retests + ±0.5/1/2/3 ATR zones
  • G. Regime context (4): vol_regime, trend_regime, session, concurrent_pattern_ids
  • H. Path snapshots (9): 5min, 15min, 30min, 1h, 3h, 6h, 24h, 72h, 168h
  • I. Path summary (3): pnl_atr_final, velocity, time_in_profit_pct
  • K. v4.1 (7): htf_d1_trend, htf_d1_atr_ratio, htf_d1_rsi, htf_d1_dist_ema200, spread_anomaly_ratio, dist_to_swing_high_atr, dist_to_swing_low_atr
  • J. Other (12): magic, comment, run timestamps, account, slippage, build time, ATR pips, bar/tick counters, reserved fields

Configuration

  • Backtest period: 2026-01-25 to 2026-04-25 (3 months)
  • Tick mode: Every tick based on real ticks (Exness Trial14)
  • MAX_TRACKED_POSITIONS: 50,000
  • Time stop: 240h (uniform across all TFs)
  • Risk per trade: 0.01% (small for testing)
  • No trade limit, no concurrent limit, no filter — all 177 patterns fire on signal
