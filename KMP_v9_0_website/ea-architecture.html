Tick Loop Flow

  1. OnTick: emergency dd check → UpdateActivePositions → if new bar: ProcessClosedBar
  2. UpdateActivePositions: per active position → compute dir_pnl_atr → MFE/MAE update → barrier sweep (TP+SL with bitset+early-exit) → path snapshots → touch counts → early-exit check (±10 ATR / 240h)
  3. ProcessClosedBar: CIndicatorManager.CaptureSnapshot → CMasterPatternDetector.DetectAll → for each fired pattern: OpenForPattern
  4. OpenForPattern: compute lot → place order → fill v4.1 fields (incl. HTF, spread, swing) → store in g_tracked[] slot
  5. OnTradeTransaction(DEAL_ENTRY_OUT): compute final fields (mfe_pct_of_life, velocity, time_in_profit_pct) → write CSV row → free slot

Performance Optimizations (v4.0+)

  • Sorted barrier loops with bitset short-circuit (skip already-hit levels)
  • Cached indicators per bar (no recompute on every tick)
  • Lazy regime updates (every 100 ticks)
  • String operations only at trade close (no per-tick formatting)
  • Early-exit at ±10 ATR cuts avg holding life from 240h → ~70h (-70% CPU)
