ส่วนที่ 2 · คำศัพท์ trading ที่ต้องเข้าใจก่อน

ทำไมต้องเข้าใจคำศัพท์เหล่านี้? เพราะตัวเลขทุกหน้าในเว็บใช้คำเหล่านี้ — ถ้าไม่เข้าใจจะอ่านเลขผิดและตัดสินใจผิด

2.1 R-Multiple (ตัว R)

R = หน่วยความเสี่ยง 1 R = ขนาดของ SL ที่กำหนด

ตัวอย่าง: ถ้า SL = 50 pips · TP = 100 pips → กำไร = +2R · ขาดทุน = -1R

ใช้ R-multiple แทนเป็นเงิน เพราะเปรียบเทียบ pattern ได้ตรงๆ ไม่ขึ้นกับขนาด lot · pip value

2.2 ATR (Average True Range)

ค่าเฉลี่ยช่วงราคาขึ้น-ลงต่อแท่ง · ใช้วัด volatility ของตลาด

ทุก SL/TP ในเว็บนี้ใช้ ATR-based ไม่ใช้ pip คงที่ เช่น SL 0.5×ATR หมายถึง SL = ครึ่งหนึ่งของ ATR ปัจจุบัน

ทำไมใช้ ATR? ทำให้ pattern ทำงานได้ทุกตลาด — XAU ATR 200 pip ก็ต่างจาก EUR ATR 30 pip · แต่ใน R-multiple เท่ากัน

2.3 RR (Risk-Reward Ratio)

อัตราส่วน กำไรที่ตั้งไว้ : ความเสี่ยง

ComboSLTPRRหมายความว่า
sl0.5_tp1.00.5×ATR1.0×ATR1:2เสี่ยง 1 ได้ 2
sl0.5_tp3.00.5×ATR3.0×ATR1:6เสี่ยง 1 ได้ 6
sl0.5_tp5.00.5×ATR5.0×ATR1:10เสี่ยง 1 ได้ 10
sl1.0_tp2.01.0×ATR2.0×ATR1:2SL กว้างกว่า · entry ต่างจุด

2.4 Win Rate (WR%)

เปอร์เซ็นต์ครั้งที่ trade ปิดบวก (TP hit ก่อน SL hit)

กฎสำคัญที่ต้องจำ: RR ยิ่งสูง → WR ยิ่งต่ำ (เป็นธรรมชาติของตลาด)
  • RR 1:1 → ต้อง WR > 50% ถึงจะกำไร
  • RR 1:2 → ต้อง WR > 33% ถึงจะกำไร
  • RR 1:5 → ต้อง WR > 17% ถึงจะกำไร
  • RR 1:10 → ต้อง WR > 9% ถึงจะกำไร

2.5 EV (Expected Value)

กำไรเฉลี่ยต่อ trade เป็น R-multiple

EV = (WR × R_win) - ((100-WR) × R_loss) / 100
ตัวอย่าง: WR 56.8%, RR 1:2 → EV = (56.8 × 2 - 43.2 × 1) / 100 = +0.704R

EV เป็น metric ที่สำคัญที่สุด — บอกว่า trade เฉลี่ยกำไร R เท่าไหร่

2.6 PF (Profit Factor)

อัตราส่วน กำไรรวม / ขาดทุนรวม

PFความหมาย
< 1.0🔴 ขาดทุน
= 1.0🟡 เสมอตัว
1.0 - 1.5🟢 กำไรน้อย
1.5 - 2.0🟢 ดี
2.0 - 3.0💚 ดีมาก
> 3.0💎 ยอดเยี่ยม (อาจ overfit ถ้า sample เล็ก)

2.8 MFE / MAE

MFE (Maximum Favorable Excursion) = ราคาวิ่งไปทางถูกมากที่สุดก่อนปิด trade

MAE (Maximum Adverse Excursion) = ราคาวิ่งไปทางผิดมากที่สุดก่อนปิด trade

ใช้บอก quality ของ entry — entry ดี = MFE สูง · MAE ต่ำ (ราคาวิ่งทางถูกทันที)

ศัพท์ความหมาย
FVG (Fair Value Gap)ช่องว่างราคาที่ market ยังไม่ deliver — ราคามักกลับมาเติม
Breaker Blockorder block ที่ราคา break แล้วกลายเป็น support/resistance

Daily Biasทิศทางหลักของวัน — ดูจาก HTF

3.4 SL/TP Heatmap (Grid)

เป็นตาราง 4×4 หรือ 5×5 แสดง EV ของทุก SL × TP combo · สีเข้มขึ้น = EV สูงขึ้น

  • วิธีอ่าน: หา cell สีเขียวเข้มสุด = combo ที่ดีที่สุดสำหรับ pattern × asset นี้
  • เช็ค n column ของแต่ละ row — sample ใหญ่ = เชื่อได้
  • ระวัง: cell มุมขวาบน (SL ใหญ่ + TP ใหญ่) มักให้ค่าสูงเทียม เพราะ sample เล็กลง

3.5 Path Trajectory Chart

กราฟแสดง การเคลื่อนตัวของ trade เฉลี่ย ที่ checkpoints 1h, 6h, 12h, 24h, 48h, 72h, 120h, 168h, 240h

  • Curve โค้งขึ้นทันที = pattern ทำงานเร็ว (entry ดี)
  • Curve โค้งช้า = ต้องรอนาน · อาจต้องใช้ TF ใหญ่กว่า
  • Curve ลงก่อนแล้วขึ้น = MAE ลึก · ต้อง SL กว้างกว่าค่า default

3.6 Time Decay Chart

แสดง cumulative TP/SL hit rate ตามเวลา

  • เส้น เขียว (TP hit) ขึ้นเร็ว = trade close fast
  • เส้น แดง (SL hit) ขึ้นเร็ว = pattern ผิดบ่อยช่วงต้น
  • ดู median hours to TP เพื่อตั้ง expectation: trade เฉลี่ยใช้กี่ชั่วโมง

8.1 ข้อจำกัดที่ต้องรู้

1. ข้อมูลเป็น in-sample
Pattern detection rules ตั้งจากข้อมูลเดียวกับที่ทดสอบ → bias ขึ้น 30-50%
แก้ไข: ใช้ค่า EV × 0.5 ถึง 0.7 เป็นมาตรฐาน expected OOS · หรือทำ OOS test (3-5 ปี future data)
2. ไม่รวม spread/commission/slippage
EA harvester เก็บ "real fills" ของ MT5 Tester แต่ไม่รวม cost ของ live brokers
แก้ไข: ลบ -0.05R ถึง -0.15R ออกจาก EV ที่เห็น
3. Sample bias ใน BTC/ETH M15
EA เก่ามี MAX_TRACKED_POSITIONS = 10000 → BTC/ETH M15 chop รายการ ~20-30%
✅ แก้ไขแล้ว v9.0: bump เป็น 50K + rerun เสร็จ · ปัจจุบัน v9.1 ครบ 23 assets
4. Pattern บางตัวไม่ fire (P69, P70, P100, P111, P113, P114, P131, P134, P164, P177)
ตลาดไม่ตรงเงื่อนไข academic ระหว่าง test window → ไม่ใช่ bug · เป็น research finding
ใน live อาจ fire ได้ในตลาดอื่น

8.2 FAQ

Q: ถ้าเลือก 1 pattern เดียวเทรดทุก asset ทำได้ไหม?

A: ทำได้แต่ WR จะลดลงเหลือ ~44% (จาก 56.8% ที่ best case) เพราะ asset แต่ละตัวมี behavior ต่างกัน · กลยุทธ์ที่แนะนำ: ใช้ P140 + P141 (Bull+Bear Kumo Twist) บน H1 timeframe · expected EV ~+0.33R/trade

Q: เงินทุนเท่าไรพอ?

A: $10,000 USD ขั้นต่ำ สำหรับเทรด 12-23 assets พร้อมกัน · risk 0.5%/trade · expected return realistic +50-100%/year หลัง OOS discount

Q: เลือกแค่ M15 หรือต้องดู H1, H4 ด้วย?

A: ขึ้นกับ trading style:

  • EA Bot เทรดอัตโนมัติ → M15 (เทรดถี่ · 19 ครั้ง/วัน)
  • Manual trading → H1 (5 ครั้ง/วัน · ดูทุกชั่วโมง)
  • Position trading → H4 (1-2 ครั้ง/วัน · เช็คเช้า-เย็น)

Q: ถ้า WR ใน live ต่ำกว่าที่เว็บแสดง ควรทำยังไง?

A: ปกติ — เพราะเว็บแสดง in-sample · live จะ -10-15% · ถ้า:

  • ลด < 10%: ปกติ (เช่น 56.8% → 50%)
  • ลด 10-15%: เริ่มเฝ้าระวัง
  • ลด >15%: หยุดเทรด · re-evaluate

Q: ใช้ broker ไหนได้?

A: ทดสอบใน Exness Pro · MT5 · standard contracts (USTEC ไม่ใช่ USTEC_x100, US500 ไม่ใช่ US500.cm) · brokers อื่นที่มี standard CFD ก็ใช้ได้ แต่ spread/commission อาจต่างกัน

Q: ต้องเขียน EA เองไหม?

A: ระบบนี้เป็น research dashboard ไม่ใช่ EA ใช้งานจริง · ต้องเขียน Production EA แยก โดยใช้ pattern logic + best SL/TP จากเว็บ

Q: เห็นเลขในเว็บไม่ตรงกับใน MT5 ของผม ทำไม?

A: เพราะ:

  • เว็บใช้ ATR-based SL/TP ไม่ใช่ pip · ต้อง convert
  • เว็บเก็บ real fills ใน MT5 Tester · spread ตอน backtest
  • Live spread ของ broker จะกว้างขึ้นในข่าว
