Detection Flow (per-bar)

เริ่มเมื่อบาร์ใหม่เปิด — รัน ProcessClosedBar(shift=1) วิเคราะห์บาร์ที่เพิ่งปิด

  1. OnTick: ตรวจ iTime(0) ว่าเป็นบาร์ใหม่หรือไม่ (ถ้าใช่ → step 2)
  2. iBars check: ต้องมี ≥250 bars history (warm-up safety)
  3. Indicators.CaptureSnapshot(shift=1): เก็บค่า ATR, EMA, BB, RSI, MACD, Stoch, ADX, Ichimoku ของบาร์ที่ปิดแล้ว · ทั้งหมด 70 fields
  4. MasterDetector.DetectAll(): รัน 18 sub-detectors (Cat A → R) เพื่อ check ทุก 177 patterns พร้อมกัน · set flags.PXX_* bool fields
  5. flags.CountAndScore(): รวม total_count, long_score, short_score · สำหรับ context
  6. For each pattern that fired: ถ้า direction เป็น 1 หรือ -1 → OpenForPattern(pid, direction, ...) · ถ้า agnostic → split เป็น 2 ออเดอร์ (long + short)
  7. OpenForPattern: เปิด market order ที่ current ASK/BID · บันทึก slot ใน g_tracked[] array · capture entry snapshot
  8. Per-tick (between bars): UpdateActivePositions() รัน MFE/MAE/path/virtual SL-TP/time-stop
  9. OnTradeTransaction: เมื่อ broker ปิด position → fill exit data → Logger.WriteRecord() → free slot

Pattern Detection Pattern (template)

ทุก pattern ใน Cat *.mqh files ใช้โครงเดียวกัน:

Class Structure
class CSomePatterns {
public:
  void Init(string symbol, ENUM_TIMEFRAMES period);
  void SetParams(double param1, int param2, ...);  // optional
  void DetectAll(int shift, PatternFlags &flags, 
                 const IndicatorSnapshot &snap,
                 const IndicatorSnapshot &prev_snap,
                 bool prev_valid);
  
private:
  bool DetectPatternXBull(int shift, double atr);   // ส่วนใหญ่ pattern ใช้ shift=1
  bool DetectPatternXBear(int shift, double atr);
  // ...
};
หลักการสำคัญ: ทุก detector ใช้ shift argument เป็น offset จากบาร์ปัจจุบัน (=current_bar - shift) — สำหรับ harvester เรียกด้วย shift=1 = บาร์ที่เพิ่งปิด (ป้องกัน look-ahead bias)

Compilation Requirements

  • Platform: MetaTrader 5 (MQL5)
  • MetaEditor version: Build 4760+
  • Standard libraries used: Trade/Trade.mqh (CTrade), Trade/PositionInfo.mqh (CPositionInfo)
  • External dependencies: ไม่มี — pure MQL5
  • Memory: Up to 10,000 concurrent positions tracked (configurable)
  • CSV output path: MQL5/Files/KMP_Harvest_<symbol>_<tf>.csv
Compile-safe: 0 errors expected. ทุกไฟล์มี header guards (#ifndef ... #define ... #endif) · 18 sub-detector classes init/dispatch ผ่าน CMasterDetector
